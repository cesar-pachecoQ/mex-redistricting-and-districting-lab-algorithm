# mex-redistricting-and-districting-lab-algorithm

Proyecto para distritacion y redistritacion en Mexico.

## Objetivo

Desarrollar y comparar algoritmos exactos, heuristicos, metaheuristicos y de machine learning para construir distritos y redistritos bajo restricciones geograficas y poblacionales.

## Estructura

- `data/`: datos crudos y procesados
- `src/redistricting_lab/`: codigo principal
- `configs/`: configuraciones de experimentos
- `reports/`: salidas, metricas y mapas
- `docs/`: documentacion tecnica

## Inicio rapido

```bash
uv sync
uv run python -m redistricting_lab
```
